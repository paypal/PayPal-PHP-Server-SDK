# Contributing
Thanks for your interest in this repository.
This repo is published **source-available** for transparency, education, and review. It is maintained internally, and we are not accepting external contributions at this time.
## What this means in practice
- **No pull requests.** This repository does not accept PRs.
- **Issues and Discussions are disabled.** This repo is not used to track bugs, feature requests, or questions — see [Reporting bugs and getting support](#reporting-bugs-and-getting-support) below for where those go instead.
- **No forks-to-merge workflow.** You're welcome to fork the repo for your own learning, experimentation, or internal use (subject to the [LICENSE](./LICENSE)), but forks won't be merged back upstream.
- **No roadmap input via this repo.** Product and engineering direction for this SDK is set internally and isn't decided through public discussion here.
## Reporting bugs and getting support
GitHub Issues and Discussions are disabled on this repository — it is not monitored for bug reports, feature requests, or questions submitted that way.
If you're a PayPal partner or merchant, route any issue with this SDK — bugs, security concerns, integration questions, or anything else — through PayPal's standard developer support intake process at https://www.paypal.com/us/cshelp/technical. Please do not attempt to reach the maintainers directly through GitHub.
If you're a PayPal employee, use the standard internal support/ticketing process for this SDK's owning team rather than this repository.
